1. Executive Summary & UX Vision

NOVA Home is designed as an ultra-modern, high-impact intelligent smart home engineering platform. The UI/UX vision centers on Instant Cognitive Clarity, High-Tech Dark Aesthetics, and Explainable AI Interaction.

Evaluators and homeowners can view critical telemetry (Temperature, Humidity, Ambient Light, Motion) and perimeter security status within 3 seconds of opening the interface, with instantaneous low-latency control over IoT actuators.

4. UI Component Architecture

Security Panel Component

Dynamic banner monitoring physical perimeter states. Toggles between SYSTEM SECURE (Emerald Green) and PERIMETER ALERT (Pulsing Red) when doors/windows are opened.

Sensor Telemetry Card

Includes FontAwesome category icon, sensor badge (e.g. DHT22), numeric value in Fira Code font, horizontal progress gauge, and thermal/moisture status message.





Actuator Control Item

Integrates custom rounded toggle switches, PWM brightness/speed sliders, state labels, and active visual glowing feedback upon activation.

Explainable AI Module

Provides transparent AI reasoning via Explain Condition, Suggested Action, rule tags, and a 1-click Apply AI Action button.

5. Accessibility & Information Architecture

Navigation Structure: Sticky top header bar with active scroll-spy detection highlighting current viewports (Dashboard, Architecture, Hardware Flow, AI Pipeline, GPIO Map).

Accessibility Compliance: Exceeds WCAG 2.1 AA standard for color contrast ratio (> 7:1 for main text). High-contrast icons accompany color badges to ensure color-blind accessibility.
